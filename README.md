# Random PDF Generator

## Instalation

### Clone the repo

```bash
git clone https://github.com/1hreeam/random-pdf-generator.git
```

### Install the dependencies

```bash
cd random-pdf-generator
python -m pip install -r requirements.txt
```

## Usage

Run:

```bash
python ./main.py
```
